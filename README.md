# ✊ ✋ ✌️ Rock, Paper, Scissors Game in Python

A terminal-based interactive game built using Python that allows users to play against an automated computer opponent with real-time score tracking.

## 🚀 Features
- Optimized game rules utilizing Python dictionaries instead of multiple nested `if-else` loops.
- Dynamic score tracking for both User and Computer.
- Clean validation checks for user inputs.
